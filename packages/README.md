# packages

Структура зафіксована ADR-0002 (Accepted 2026-09-14).

| Пакет | Стан |
|---|---|
| `core-model` | **реалізується** — PRNG, атрибути 1–20, модель бійця |
| `data` | **реалізується** — вагові категорії, генерація імен, генератор світу |
| `ai` | порожній |
| `engine-fight` | порожній — наступний етап |
| `engine-world` | порожній |
| `session` | порожній |
| `sim-cli` | порожній — потрібен для 10 000 прогонів гейту фази 0 |

Залежності односторонні: `apps` → `session` → `engine-*` → `ai` → `data` → `core-model`.
