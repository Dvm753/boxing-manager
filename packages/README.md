# packages

Структура зафіксована ADR-0002 (Accepted 2026-09-14).

| Пакет | Стан |
|---|---|
| `core-model` | **реалізується** — PRNG, атрибути 1–20, модель бійця |
| `data` | **реалізується** — вагові категорії, генерація імен, генератор світу |
| `ai` | **реалізується** — політика менеджера, матчмейкінг |
| `engine-fight` | **реалізується** — рушій бою, гейт фази 0 зелений |
| `engine-world` | **реалізується** — календар, тік дня, рівні, рейтинги |
| `session` | порожній |
| `sim-cli` | **реалізується** — калібрування і прогін сезону |

Залежності односторонні: `apps` → `session` → `engine-*` → `ai` → `data` → `core-model`.
