# @bm/i18n

Словники подання. **Не залежить від симуляції і симуляція не залежить від нього** (ADR-0017):
`engine-*`, `ai` і `data` оперують ідентифікаторами й не містять тексту для людини.

## Стан перекладів

| Мова | Код | Стан |
|---|---|---|
| Українська | `uk` | основна, еталон набору ключів |
| Англійська | `en` | повний |
| Французька | `fr` | **потребує вичитки носієм** |
| Німецька | `de` | **потребує вичитки носієм** |
| Іспанська | `es` | **потребує вичитки носієм** |
| Італійська | `it` | **потребує вичитки носієм** |

Переклади fr/de/es/it зроблені без носія мови. Боксерська термінологія має усталені відповідники
в кожній мові, і дослівний переклад тут гірший за запозичення — тому вичитка обов'язкова
перед релізом. Це зафіксований борг, а не готовий стан.

## Додати мову
Один файл у `src/locales/`. Коду правити не треба. Тест повноти впаде, якщо бракує ключів.
