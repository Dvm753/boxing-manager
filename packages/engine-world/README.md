# @bm/engine-world

Тік дня, рівні деталізації, події домену. Чистий пакет: без I/O, годинника і глобального стану.

- Календар — власний, арифметичний. `Date` заборонений (ADR-0003).
- `advanceDay` не змінює стан напряму: породжує події, які застосовують обробники (ADR-0016).
- Рівень деталізації — похідна від стану, не збережене поле (ADR-0015).
