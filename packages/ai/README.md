# @bm/ai

Політики рішень: менеджери, промоутери, бійці. Чистий пакет — без I/O, годинника
і глобального стану.

**Не імпортує `engine-world`.** Усе потрібне зі світу приходить простими структурами
(`MatchCandidate`), інакше залежність стала б круговою (ADR-0002).

Гравець і ШІ користуються тим самим розрахунком оцінки пропозиції — вимога `WORLD_ENGINE_SPEC.md`.
