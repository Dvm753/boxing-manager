# Definition of Done

Задача вважається завершеною, тільки коли виконано **всі** пункти:

- [ ] Реалізовано рівно те, що описано в задачі — без «бонусів»
- [ ] Тести написані і зелені
- [ ] Тест детермінізму зелений (для змін у рушіях)
- [ ] Статистичні golden-тести зелені (для змін у `engine-fight`)
- [ ] Немає `Math.random()` у пакетах рушіїв
- [ ] Немає нових залежностей без ADR
- [ ] `STATE.md` оновлено в тому ж коміті
- [ ] Запис у `ACTION_JOURNAL.md` додано
- [ ] Сформовано демонстраційну web-збірку і надіслано власнику
      (`governance/DEMO_BUILD_PROTOCOL.md`; для етапів, що змінюють поведінку симуляції)
- [ ] Публічні інтерфейси модуля відповідають `docs/MODULE_CONTRACTS.md`
