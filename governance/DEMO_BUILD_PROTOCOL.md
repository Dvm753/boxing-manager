# Протокол демонстраційної збірки

> Причина існування: горизонтальний порядок робіт (`ROADMAP.md`) означає, що рушій доводиться до
> статистичної відповідності раніше, ніж з'явиться гра. Ризик цього підходу названий прямо в
> альтернативній концепції: «примітивний MVP не покаже, чи гра цікава». Демонстраційна збірка —
> компроміс: порядок робіт лишається горизонтальним, але результат кожного етапу видно й можна
> помацати.

## Правило

**Після кожного завершеного етапу програмування формується web-збірка, яку власник може завантажити
і запустити.** Етап без збірки не вважається завершеним (див. `DEFINITION_OF_DONE.md`).

## Вимоги до збірки

| Вимога | Чому |
|---|---|
| **Один самодостатній HTML-файл** | завантажив, відкрив подвійним кліком — працює. Без сервера, без `npm install`, без інтернету |
| Працює з `file://` | немає модулів, що вимагають CORS; усе інлайниться в один файл |
| Без мережевих запитів | збірка має працювати офлайн і не залежати від живих CDN |
| Показує **стан симуляції**, а не макет UI | демонструється те, що справді працює, а не намальовані екрани |
| Містить seed і версію | будь-що побачене можна відтворити: той самий seed дає той самий результат |
| Має розділ «Що працює / Чого ще немає» | щоб очікування збігалися з реальністю |

## Чого збірка не робить

- **Не є грою.** До фази 1 це інструмент спостереження за симуляцією, а не інтерфейс гравця.
- **Не є прототипом UI.** Візуальні рішення фази 3 через неї не приймаються.
- **Не містить правил домену.** Інваріант із `MODULE_CONTRACTS.md` діє і тут: збірка лише відображає
  результати роботи пакетів, жодних обчислень у поданні.

## Іменування і доставка

```
boxing-manager-demo-<фаза>.<етап>-<YYYY-MM-DD>.html
```
Файл надсилається власнику в чат і **не комітиться в репозиторій** — це артефакт збірки,
а не джерело. Каталог `/dist-demo/` внесено в `.gitignore`.

Відтворюється командою:
```
npm run demo
```

## Зв'язок із гейтами

Збірка **не замінює тести**. Вона показує, а тести доводять. Етап, у якому збірка виглядає добре,
а golden-тести червоні, вважається проваленим — `AGENTS.md` §5 діє без винятків.
