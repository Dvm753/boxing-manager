# Специфікація рушія бою

> Статус: **чернетка**. Формули не зафіксовані. Це найдорожчий для зміни документ у проєкті —
> перед кодом він має бути затверджений окремо.

## Ієрархія
`Бій → Раунд → Обмін (exchange, ~5–10 с) → Дія → Удар`
12 раундів × 20–30 обмінів ≈ 250–350 тіків на бій.

## Стани позиції (ланцюг Маркова)
`out-of-range → long (джеб) → mid (силова) → inside → clinch → ropes/corner → down`

Перехід визначається намірами обох бійців, роботою ніг, силою, втомою і стилем.

## Цикл обміну
1. **Ініціатива** — f(робота ніг, швидкість рук, ринговий IQ, агресія, втома, стан)
2. **Вибір дії** — політика стилю + гейм-план + вказівки кутка + усвідомлення рахунку
   Дії: джеб, подвійний джеб, комбінація, силовий одиночний, по корпусу, фінт, розрив дистанції, вхід у ближній, клінч, глухий захист, чекання контратаки
3. **Влучання** — `p_land = base(тип) × f(точність, швидкість) / f(захист, рухи головою, дистанція) × втома × шкода × модифікатор стану`
4. **Шкода** — три незалежні накопичувачі: **голова**, **корпус**, **витривалість**
5. **Травми в бою** — розсічення (з локацією), набряк (звужує огляд), зламана рука, ребра
6. **Нокдаун** — поріг накопиченої шкоди + окремий шанс «флеш-нокдауну», модифікований підборіддям, втомою, балансом; далі рахунок, перевірка здатності продовжити, стан `hurt` на N обмінів
7. **Зупинка** — рефері (беззахисність), лікар (розсічення), кут (рушник), правило трьох нокдаунів (опційне за комісією)
8. **Суддівство** — 3 судді, кожен із вектором упереджень (вага чистих влучань / агресії / контролю рингу / захисту, домашня перевага, вага імені), система 10 очок

## Статистика
По раундах: кинуто/влучено × (джеб / силові) × (голова / корпус). Основа CompuBox-екрана і аналітики.

## Калібрування (гейт фази 0)
10 000+ прогонів. Цільові коридори зафіксовані в **ADR-0008**, обсяг гейту — в **ADR-0009**.

У гейті фази 0:
- **M1** частка дострокових (KO+TKO+RTD) — окремо по трьох вагових групах; додатково перевіряється,
  що важка вага строго вища за легку з розділеними інтервалами
- **M3** частка нічиїх — коридор 2.0–4.0%
- **M4** частка роздільних і неодностайних рішень — коридор 22–31%

Перенесено в гейт фази 1 (даних не існує): **M2** розподіл раунду зупинки,
**M5** середня кількість нокдаунів. Попри відсутність тестів, `EventLog` **зобов'язаний**
писати `ending_round` і нокдауни з першого дня — інакше тест неможливо буде додати без переробки рушія.

Орієнтири без тестів: **M6** удари за раунд, **M7** влучність джеба і силових —
знімки CompuBox різних років, перевірка на здоровий глузд, не гейт.
