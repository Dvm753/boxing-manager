# Boxing rules, purse bids and disclosed-purse research package

Date checked: 2026-09-23

## Contents
The Excel workbook contains:
1. **Rules Matrix** — WBC, WBA, IBF and WBO purse-bid / sanction-fee / mandatory-cycle rules.
2. **Official Sources** — direct source URLs.
3. **Fury-Whyte 2022** — WBC chronology and purse-bid economics.
4. **Ali Act & Manager Caps** — federal disclosures/firewall and CA/NV/NJ/TX state-layer findings.
5. **Money Layer - 100 Purses** — exactly 100 disclosed/commission-filed purse records from $800 pro-debut level through $100m PPV base purse.
6. **State Data Availability** — what could and could not be obtained for California, Nevada, Texas and New Jersey.
7. **Game Modelling Inputs** — normalized variables for implementation.

## Important source-quality distinctions
- California rows are taken directly from **California State Athletic Commission supervisor reports**.
- Nevada rows are contemporaneous reports explicitly reproducing figures **released/filed by the Nevada State Athletic Commission**. They are tagged as secondary reproductions rather than direct commission PDFs.
- No comparable bulk purse table was located in the official Texas or New Jersey public interfaces reviewed. The workbook therefore does **not** fabricate or substitute unofficial purse estimates for those states.
- PPV contract/base purse is not the same as total fighter compensation. Backend PPV participation, guarantees, sponsorship and other consideration can materially increase total earnings.

## Rule-edition cautions
- WBC download page says its Rules & Regulations file was last updated **20 February 2026**.
- WBA current URL/file name contains “2023”, but the PDF itself says **amended December 2022 and April 2024** and includes a 2025 female-fee appendix.
- IBF file is the official **06/25** Championship Contest Rules, with amendments through April 2025.
- WBO regulation PDF is posted under **January 2024**.

## Critical WBA inconsistency
Chapter D.3 states a $5,000 purse-bid participation fee, while current Appendix D lists weight-based participation fees of $5,000 / $7,500 / $10,000 / $15,000. This is preserved as an internal-document inconsistency rather than silently resolved.

## Files not bundled
The public rule PDFs could be read and verified on the web, but the runtime download channel could not resolve the external domains. The workbook contains direct URLs to each official PDF/document so they can be downloaded from the source.
