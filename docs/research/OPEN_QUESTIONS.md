# Відкриті питання

Сюди агент записує все, що виявив, але не має права робити. Питання не видаляються — закриваються посиланням на ADR або рішення.

## Блокують фазу 0 (потрібні перед кодом рушія)

| № | Питання | Навіщо |
|---|---|---|
| Q1 | Цільові статистичні розподіли реального боксу: частка KO/TKO окремо по вагових категоріях, розподіл раунду зупинки, частка нічиїх і split decision, середня кількість ударів за раунд | Без цих чисел golden-тести неможливі, а гейт фази 0 нездоланний |
| Q2 | Шкала атрибутів: 1–20 як у FM чи 1–100 | Впливає на всі формули; змінювати пізно — дорого |
| Q3 | Тривалість обміну: фіксовані 5–10 с чи змінна залежно від дії | Визначає роздільність рушія |
| Q4 | Модель втоми: лінійне виснаження чи два баки (анаеробний/аеробний) | Найбільше впливає на «відчуття» пізніх раундів |
| Q5 | Чи моделювати ефект розмаху рук і зросту явно, чи через атрибут контролю дистанції | Впливає на матчапи |
| Q6 | Формат `FightEvent` — публічний контракт, змінювати пізніше дорого | Від нього залежить і UI, і повтори |
