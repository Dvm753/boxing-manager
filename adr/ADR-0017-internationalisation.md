# ADR-0017: Багатомовність

- **Статус:** Accepted
- **Дата:** 2026-09-14
- **Погоджено:** 2026-09-14
- **Клас зміни:** A

## Контекст
Гра має підтримувати перемикання мови: англійська, французька, німецька, іспанська, італійська,
українська. Українська — основна на час розробки.

Рішення потрібне зараз, а не у фазі 3. Причина конкретна: у `packages/data` уже з'явилося поле
`nameUk` у довіднику вагових категорій. Це **порушення інваріанта 1** з `ARCHITECTURE.md`
(симуляція не містить подання) і водночас пастка: чим довше жити з текстом усередині даних,
тим дорожче його звідти витягати. Виявлено при погодженні цього ADR і виправляється ним.

## Рішення

### Правило
**Симуляція і дані не містять тексту для людини.** Вони оперують ідентифікаторами;
подання перетворює ідентифікатор на рядок обраною мовою.

```
packages/data     { id: 'flyweight', limitKg: 50.8, group: 'light' }   ← без назв
packages/i18n     uk: { 'weightClass.flyweight': 'найлегша' }
                  en: { 'weightClass.flyweight': 'flyweight' }
apps/web          t('weightClass.flyweight') → «найлегша»
```

Поле `nameUk` з `weight-classes.json` **видаляється**.

### Пакет `packages/i18n`
- Розташування в графі залежностей — **збоку від симуляції**: `apps` і `session` можуть від нього
  залежати, `engine-*`, `ai` і `data` — ні. Лінт-правило те саме, що для зворотних імпортів.
- Словники — JSON по одному на мову, ключі плоскі й крапкові: `attribute.jab`, `method.TKO`.
- Відсутній ключ **не падає мовчки**: у режимі розробки видно сам ключ, у тестах — помилка.
  Мовчазний відкат на англійську ховає прогалини до релізу.

### Множина
Українська має три форми (1 бій / 2 бої / 5 боїв), англійська дві, французька свої правила.
Використовується `Intl.PluralRules` — стандарт платформи, без зовнішньої залежності.
`Intl` дозволений **тільки в подання**: у рушіях він заборонений нарівні з `Date` (ADR-0003),
бо його поведінка залежить від середовища.

### Чого **не** перекладаємо
- **Імена бійців, залів, промоушенів.** Це власні назви, згенеровані за регіональними профілями.
- **Ідентифікатори в збереженнях.** Сейв не залежить від мови інтерфейсу — мова є налаштуванням
  подання, не частиною світу.

## Наслідки
- Нова мова = один JSON, без правок коду.
- Тест повноти словників: набір ключів кожної мови збігається з українським.
  Неповний переклад ловиться тестом, а не гравцем.
- Переклади на fr, de, es, it зроблені без носія мови і **потребують вичитки перед релізом**.
  Позначено в `packages/i18n/README.md`; це борг, а не готовий стан.
- Термінологія боксу різними мовами має усталені відповідники (purse, mandatory, unification) —
  дослівний переклад тут гірший за запозичення. Вичитка обов'язкова саме через це.

## Перевірка
- У `packages/data`, `packages/engine-*`, `packages/ai` немає рядків, призначених людині —
  перевіряється тестом на заборонені поля (`name*`, `label*`, `description*`).
- Набори ключів усіх мов збігаються.
- Кожен ключ, використаний у подання, існує в словнику.
