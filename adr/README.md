# ADR — журнал архітектурних рішень

Одне рішення = один файл. Нумерація наскрізна, файли не видаляються.

Статуси:
- `Proposed` — пропозиція. **Реалізовувати заборонено.**
- `Accepted` — погоджено власником словом «Погоджено». Можна реалізовувати.
- `Superseded by ADR-XXXX` — скасовано пізнішим рішенням.
- `Rejected` — відхилено, лишається в історії з причиною.
