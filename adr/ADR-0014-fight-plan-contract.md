# ADR-0014: Контракт плану бою

- **Статус:** Accepted
- **Дата:** 2026-09-14
- **Погоджено:** 2026-09-14
- **Клас зміни:** A
- **Джерело:** `docs/analysis/ALT_CONCEPT_REVIEW.md` §4.4

## Контекст
Концепція пропонує адаптивний план бою центральною механікою: план на блоки раундів, інформація
в кут між раундами, можливість перемкнути план. Реалізація цього — фаза 1, але **рушій має приймати
план на вхід із першого дня**: додати параметр у сигнатуру після написання рушія означає переписати
його цикл вибору дії.

Погоджено зафіксувати **контракт зараз, реалізацію потім**.

## Рішення
`simulateFight` приймає план для кожного бійця. Структура:

```ts
interface RoundBlockPlan {
  fromRound: number;
  toRound: number;
  /** Зсуви осей стилю (ADR-0011) на цей блок раундів. */
  axisAdjustments: Partial<StyleAxes>;
}

interface FightPlan {
  /** Базові осі на бій: осі бійця плюс вказівки на весь бій. */
  baseAxes: StyleAxes;
  /** Блоки раундів, що перекривають базові осі. */
  blocks: readonly RoundBlockPlan[];
  /** Вказівки під конкретного суперника. Фаза 1. */
  opponentInstructions: readonly OpponentInstruction[];
}
```

Порожній план (`blocks: []`, `opponentInstructions: []`) означає «бійся за своїми осями» —
це поведінка фази 0.

## Розмежування повноважень
ADR-0007 зробив гравця менеджером, а не тренером. Тому:

- **Гравець задає план до бою.** Це менеджерське рішення.
- **Між раундами рішення ухвалює тренер** — NPC зі своїми атрибутами. Якість зчитування ситуації
  («суперник сповільнився», «правий бік набрякає») і якість реакції залежать від нього.
- Прямого керування боєм у гравця немає. Інтерфейс, що дає кнопку «змінити тактику в 7-му раунді»,
  порушує ADR-0007 де-факто.

## Наслідки
- Сигнатура `simulateFight` фіксується з планом у фазі 0 і не змінюється у фазі 1.
- `EventLog` фіксує момент зміни плану окремою подією — інакше в перегляді бою не буде видно,
  чому поведінка змінилася.

## Перевірка
Сигнатура `simulateFight(a, b, context, rng)` приймає плани в `context`; порожній план дає
поведінку за осями бійця; тест детермінізму проходить із планом і без нього.
