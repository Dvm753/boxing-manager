# ADR-0002: Структура монорепо

- **Статус:** Proposed
- **Дата:** 2026-09-13
- **Клас зміни:** A

## Контекст
Головний ризик проєкту — змішування правил гри з UI. Потрібні фізичні межі, а не домовленості.

## Рішення
```
packages/
  core-model/     сутності, типи, схеми, валідація
  data/           JSON-довідники, генератор світу
  engine-fight/   симуляція одного бою (чиста)
  engine-world/   тік дня, ШІ, економіка, рейтинги (чиста)
  session/        команди гравця, збереження, undo
  sim-cli/        масові прогони, калібрування, звіти
apps/
  web/            React-інтерфейс
```
Залежності односторонні: `apps` → `session` → `engine-*` → `data` → `core-model`.

## Наслідки
- `engine-fight` не має доступу до календаря, грошей і рейтингів. Усе потрібне передається аргументом.
- UI не може містити жодного правила домену — це перевіряється оглядом і лінт-правилом на імпорти.

## Перевірка
Лінт-правило заборони зворотних імпортів; збірка кожного пакета ізольовано.
