# Boxing Manager

Менеджерський симулятор боксу за принципами Football Manager: живий світ, детермінована симуляція бою, прихована інформація, дані окремо від коду.

## Статус
Фаза 0 (ядро без гри). Код не розпочато. Див. `STATE.md` — це єдине джерело правди про фактичний стан.

## Метод роботи
Пропозиції по одній → відповідь «Погоджено» → фіксація в ADR → реалізація → тести → наступний крок.
